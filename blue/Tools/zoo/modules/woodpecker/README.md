# Woodpecker
* An automated default password checker script. It should be able to test a default and/or anonymous login on just about any service.
  * File Sharing
    * Samba, SMB, FTP
  * WebServices
    * Wordpress, Gitea, 
  * Remote Administration
    * SSH, WinRM, RDP, LDAP, Kerberos, SMB
  * Mail
    * SMTP, IMAP, POP3
